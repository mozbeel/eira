# Eira — Lua 5.5 Source Code Documentation

> **This entire documentation folder was generated by AI.** It covers every `.c` file and

This is a Lua 5.5 interpreter and compiler built in C. The codebase is a complete
implementation: lexer → parser → code generator → bytecode serializer → virtual machine,
plus the standard libraries, C embedding API, and two CLI front-ends (`lua` and `luac`).

---

## Architecture Overview

A Lua program goes through these stages:

```
 Source text
     │
     ▼
 ┌─────────┐
 │  llex    │  Tokenizer: converts raw bytes into a stream of tokens.
 └────┬────┘
      ▼
 ┌─────────┐
 │ lparser  │  Recursive-descent parser: builds a syntax tree (statement list).
 └────┬────┘
      ▼
 ┌─────────┐
 │  lcode   │  Code generator: walks the AST and emits Lua bytecode instructions.
 └────┬────┘
      ▼
 ┌─────────┐
 │ ldump /  │  Serializes (dump) or loads (undump) the compiled Proto as bytecode.
 │ lundump  │
 └────┬────┘
      ▼
 ┌─────────┐
 │   lvm    │  Virtual machine: fetches and executes bytecode instructions one by one.
 └────┬────┘
      ▼
 Result
```

The VM relies on a runtime layer:
- **lobject** — the `TValue`, `Table`, `LClosure`, and `Proto` data structures.
- **lstate** — global interpreter state (`global_State`) and per-thread state (`lua_State`).
- **lgc** — incremental mark-and-sweep garbage collector.
- **ltable** — Lua's table implementation (hash map + array partition).
- **lstring** — interned and external string management.
- **ltm** — metamethod lookup and dispatch.

C code embedding Lua uses **lapi** (the public C API) and **lauxlib** (convenience helpers).
